Everything to pass, in one place

Five study tools built from the LobeChat-on-AWS project and the course theory (scope: DevOps → Kubernetes). They're ordered below by the sequence and priority you should use them.

The tools, in study order

Priority badge = how much it moves your grade. Click any to open.

1 · Best Exam Tool

Priority 1 · drill

160 MCQ in 4 blocks (select-to-answer, wrong ones re-appear, star + break + timer + stats), short answers by topic, and flashcards. Your main practice engine.

Use it: most of your study time. Active recall beats reading. Star weak questions and re-drill the starred set.

2 · Mega Companion

Priority 2 · deep + tricky

The maximum-detail walkthrough: the two-architecture trap, exact images/ports/IAM, the evolution story (v1→v5→our v2), and a gotcha bank of "why does this error" cases.

Use it: to learn the tricky specifics and the "why each change happened". Closest to how the teacher sets traps.

3 · Project Companion

Priority 3 · mental model

A clean component-by-component walkthrough of the LobeChat stack with sample MCQ and a "why" Q&A bank. Builds the picture before you go deep.

Use it: first, if the architecture still feels fuzzy. Read once top-to-bottom.

4 · Theory Companion

Priority 4 · foundations

General DevOps/MLOps · GitHub · CI/CD · IaC · Docker · Ansible theory, each tied back to the project. Diagrams and exam moves.

Use it: if the pure theory is rusty. Skim the blocks you're weak on.

5 · Midterm Trainer

Priority 5 · diagnostic

Your real midterm's 30 questions as an interactive quiz (practice or exam mode, scoring, review).

Use it: as a warm-up / confidence check at the start, and again the day before.

Suggested order

  1. Diagnose — run the Midterm Trainer once to see your baseline.
  2. Build the picture — read the Project Companion (and the Theory Companion for any weak topic).
  3. Go deep — work through the Mega Companion: the two-stack trap, the evolution, the gotchas.
  4. Drill hard — spend most time in the Best Exam Tool: all 4 MCQ blocks, then the short answers, then flashcards. Star what you miss and re-drill the starred set until clean.
  5. Final pass — re-do the Midterm Trainer and the Best Exam Tool "retry my mistakes" the day before.
Exam reality: 40 MCQ + 10 short answers, closed book, no LLM, pass = 5. The graded skill is explaining why things happen — answer in cause→effect form. Scope ends at Kubernetes (no SageMaker). There is also a detailed plain-text master-notes file (lobechat_exam_master_notes.txt) as your reference.
